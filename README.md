# 英语学习站（English Learning Hub）

一个纯静态的英语学习网站：**语法讲解 + 主题单词库 + 万能句型 + 场景口语 + 背单词工具**。
不需要服务器、不需要安装任何依赖、不需要联网（除了浏览器自带的发音引擎）。

## 线上地址

**https://Kaochi11.github.io/english-learning-site/**

- 仓库：https://github.com/Kaochi11/english-learning-site
- 后台：https://github.com/Kaochi11/english-learning-site/settings/pages
- 这个地址可以直接发到微信里打开，也能分享给别人。

### 以后怎么更新线上内容

两种方式：

1. **在网页上改**：进仓库 → 打开要改的文件 → 右上角铅笔图标 → 改完 Commit changes。适合改几个词、改错别字。
2. **在电脑上改完重新发布**：改好本地文件后，设置一个新的 token 再跑一次
   `tools\deploy-github.ps1`，脚本会重新推送并复用已有的 Pages 配置。

## 怎么打开

**在电脑上：** 双击 `index.html`，用 Chrome / Edge / Safari 打开就能用。

**在手机上（同一个 WiFi）：** 双击 `启动手机访问.bat`，窗口里会打印出一串地址，例如
`http://192.168.100.3:8000`。手机连上同一个 WiFi 后，在浏览器或微信里打开这串地址即可。
（也可以先把地址发到微信「文件传输助手」，再在手机上点开。）

**让任何人都能打开（推荐）：** 把网站发布到免费静态托管上，拿到一个公网链接。
见下面「发布到公网」一节。

> 发音功能依赖浏览器的 Web Speech API，Chrome / Edge / Safari 都支持。
> 微信内置浏览器（iOS 的 WKWebView / 安卓的 X5）支持不稳定，页面顶部会自动弹出提示条，
> 引导用户点右上角「···」→「在浏览器中打开」。

## 发布到公网（拿到微信里能打开的链接）

微信只能打开**公网网址**，打不开电脑上的本地文件，所以要让手机扫码/点链接使用，必须先托管。
本站是纯静态站点，没有任何后端，任意静态托管都行。现成的上传包是 `english-learning-site.zip`。

推荐几家免费、支持直接上传文件夹或 zip 的：

| 平台 | 免费额度 | 国内访问 | 说明 |
| --- | --- | --- | --- |
| GitHub Pages | 充足 | 一般可用（偶尔慢） | 需要 GitHub 账号，仓库设为 Public 后在 Settings → Pages 里开启 |
| Cloudflare Pages | 充足 | 部分网络会被墙 | 上传 zip 即可，速度不错 |
| Netlify | 充足 | 一般可用 | 拖拽文件夹到网页就能发布 |
| Vercel | 充足 | 国内经常被墙 | 国内访问不稳定，不太推荐 |

上传时请确保 **`index.html` 在根目录**（也就是打开链接直接就是首页），zip 里现在就是这个结构。

> 如果要有自己的域名（比如 `english.你的名字.com`），需要买域名并做解析；
> 使用 `.github.io` / `.pages.dev` 这类免费子域名则不用。

## 学习激励系统

背单词页内置了一套基于真实学习数据的激励层，不用注册、不联网：

- **每日目标环**：今天学了多少词，一眼可见
- **等级与 XP**：新词 10 XP、复习 4 XP、进入「已掌握」再 +20 XP；七个等级从「初学者」到「大师」
- **学习热力图**：最近 12 周每天的学习量，用颜色深浅表示
- **成就徽章**：10 个徽章，从「第一步」到「百词精通」，条件全部由本地数据判定
- **完成庆祝**：每组正确率 ≥70% 时会有一次轻量的彩带动画

## 背单词工具是怎么工作的

每个单词有一个「记忆盒子」（box 0–6）和一个到期时间：

| 盒子 | 答对后下次复习间隔 |
| --- | --- |
| 1 | 10 分钟 |
| 2 | 1 天 |
| 3 | 3 天 |
| 4 | 7 天 |
| 5 | 21 天 |
| 6 | 60 天后进入「已掌握」 |

评分有三档：

- **想起来了** → 盒子 +1，间隔变长
- **有点模糊** → 盒子不变，10 分钟后再考一次
- **完全不会** → 回到第 1 格，并在本组练习里立刻再出现一次

每组练习 = 先安排到期的复习词（最多 30 个），再补充新词（按「每日目标」计算）。
所有进度存在浏览器的 `localStorage`（键名 `en-site-progress-v1`），不会上传到任何地方。

### 快捷键

- 卡片模式：`空格` 显示答案，`1` 想起来 / `2` 模糊 / `3` 不会
- 拼写模式：`回车` 提交答案

## 怎么加内容

所有内容都在 `assets/js/data.js` 里，照着现有格式加就行，不用改任何逻辑代码。

**加一个单词：**

```js
{ w: "example", p: "/ɪɡˈzɑːmpl/", t: "n.", m: "例子，范例",
  e: "This is a good example.", z: "这是个好例子。", c: "study" },
```

`c` 字段必须是 `WORD_CATEGORIES` 里已有的 id：
`daily` / `study` / `emotion` / `travel` / `business` / `tech` / `health` / `academic` / `exam` / `spoken`。

`b` 字段是它属于哪本词书，不写默认为 `core`：
`core` / `ielts-core` / `ielts-academic` / `ielts-writing` / `ielts-speaking`。
新加词书时，记得同时在 `WORDBOOKS` 里补一条定义。

**加雅思内容：** 往 `IELTS_SKILLS` 里追加或修改。`practice.type` 支持三种：
`quiz`（选择题，需要 `items[].q / opts / answer / why`）、
`dictation`（听写，需要 `items[].en / zh`）、
`timer`（口语计时，需要 `prep`、`speak`、`cards[]`）。

**加一个语法专题：** 往 `GRAMMAR_TOPICS` 数组里追加一个对象，
必填 `title`、`en`、`level`、`intro`，可选 `rules`（数组）、`table`（表头 + 行）、
`examples`（`{en, zh, note}`）、`mistakes`（`{wrong, right, why}`）、`tip`。

**加一个口语场景：** 往 `SPEAKING_SCENARIOS` 里加，需要 `dialogue`（`{who, en, zh}`，
`who` 用 `"A"` 或 `"B"` 决定气泡在左还是在右）和 `phrases`（`{en, zh}`）。

新增分类的话，记得同时加进 `WORD_CATEGORIES`，并在 `vocabulary.html` 里补一个筛选按钮。
